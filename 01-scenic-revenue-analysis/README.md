# 烟台市 A 级景区经营模式与收入结构分析

用公开政务数据分析「景区等级」「门票策略」与「营收」之间的关系，验证一个反直觉的假设：**免门票的景区，综合收入反而更高。**

## 数据

- 来源：山东公共数据开放平台（烟台市 A 级景区经营数据）
- 规模：375 条记录、8 个字段（景区名称、景区等级、门票收入、营业收入、接待总人次等）
- 时间：2026 年数据集

## 方法与步骤

1. **字段清洗与核对**：统一数值列类型，检查缺失值（各列缺失为 0），确认「营业收入经营收入」的量级口径
2. **分组聚合**：用 `groupby` 对比「景区等级 × 是否收取门票」共 7 个分组的平均营收与平均客流
3. **交叉验证**：用 Excel 数据透视表重复一遍聚合结果，确认 Python 侧无误
4. **稳健性检查**：由于部分分组样本量较小，均值易被个别景区拉高，额外计算中位数复核结论方向

## 核心结论

1. 免门票的 4A 景区平均营收约为付费 4A 景区的 **11 倍**，且高于付费 5A 景区
2. 4A 景区内部分化明显：免门票与收费两类商业模式差异极大
3. 5A 景区高度依赖门票收入，收入结构单一

> 说明：本结论是**相关关系**，不是因果关系。免门票景区可能本身二次消费业态更成熟，才具备免票条件；要验证因果需更多年份对照数据。
